# Cipher Lock

একটি সাধারণ প্যারেন্টাল-কন্ট্রোল Android অ্যাপ। বাচ্চা ফোনে ইউটিউব দেখতে পারে, আর
অভিভাবক একটি PIN দিয়ে কতক্ষণ দেখবে তা ঠিক করে দিতে পারেন। সময় শেষ হলে স্ক্রিন
নিজে থেকেই লক হয়ে যায়।

এই রিপোজিটরি ব্যক্তিগত ব্যবহারের জন্য — পাবলিশ বা বিতরণ করার উদ্দেশ্যে তৈরি না।

## কীভাবে কাজ করে

1. **হোম স্ক্রিন** — একটা বড় "ইউটিউব দেখো" বাটন।
2. **Accessibility সার্ভিস** — বাচ্চা অন্য অ্যাপে যাওয়ার চেষ্টা করলে, অভিভাবকের
   "exit" অনুমোদন না থাকলে অ্যাপটি আবার সামনে নিয়ে আসে।
3. **টাইমার** — গিয়ার বাটনে চাপ দিয়ে PIN দিলে ১৫/৩০/৬০ মিনিটের একটা সময় বাছাই
   করা যায়। সময় শেষ হলে স্ক্রিন অটো-লক হয়ে যায়।
4. **লক স্ক্রিন** — এখান থেকে বাচ্চা নিজে বের হতে পারে না। "অভিভাবক?" বাটনে PIN
   দিলে অভিভাবক অ্যাপ থেকে বের হতে পারবেন।
5. **নোটিফিকেশন** — অ্যাপ চালু থাকলে প্রতি ২ ঘণ্টায় একটা লোকাল রিমাইন্ডার
   নোটিফিকেশন আসে। কোথাও কিছু পাঠানো হয় না, শুধু ফোনেই দেখানো হয়।

## প্রজেক্ট গঠন

```
app/src/main/
  java/com/xz/cipherlock/
    MainActivity.java            WebView হোস্ট, JS bridge, পারমিশন ফ্লো
    MyAccessibilityService.java  exit না করা পর্যন্ত অ্যাপ সামনে ফিরিয়ে আনে
    NotificationReceiver.java    প্রতি ২ ঘণ্টায় রিমাইন্ডার দেখায়
    PrefsHelper.java             SharedPreferences ভিত্তিক persistent flag
  assets/
    index.html / style.css / script.js   পুরো UI (হোম, প্লেয়ার, লক, PIN শিট)
  res/                           আইকন, স্ট্রিং, থিম, accessibility config
```

## আগে যা অবশ্যই বদলাতে হবে

- `assets/script.js`-এর `PARENT_PIN` — ডিফল্ট `"1234"`, নিজের PIN বসান।
- `app/build.gradle`-এর `applicationId` — চাইলে নিজের মতো বদলান।

## বিল্ড করা

### লোকালি (Android Studio)
সরাসরি এই ফোল্ডারটা Android Studio দিয়ে ওপেন করুন, Gradle sync হবে, তারপর
`Run` বা `Build > Build APK(s)`।

### GitHub Actions দিয়ে
`main` ব্রাঞ্চে push করলে `.github/workflows/build.yml` অটোমেটিক একটা debug
APK বিল্ড করে workflow-এর "Artifacts" অংশে আপলোড করে দেয় — ম্যানুয়ালি
`Actions` ট্যাব থেকে ডাউনলোড করা যাবে।

## সীমাবদ্ধতা (ইচ্ছাকৃতভাবে রাখা হয়নি)

- কোনো রিমোট সার্ভার/অ্যাডমিন প্যানেল থেকে লক/আনলক করার ক্ষমতা নেই।
- রিবুটের পর অ্যালার্ম/রিমাইন্ডার আবার শিডিউল করতে একবার অ্যাপ খুলতে হবে
  (BOOT_COMPLETED রিসিভার যোগ করা হয়নি)।
- এক্সাক্ট অ্যালার্ম ব্যবহার করা হয়নি, তাই নোটিফিকেশন ঠিক ২ ঘণ্টায় না হয়ে
  কাছাকাছি সময়ে আসতে পারে (Doze ব্যাচিং)।
